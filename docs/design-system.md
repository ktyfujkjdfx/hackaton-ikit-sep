# Дизайн-система «ФинКом» — положить в `docs/design-system.md`

Дать команде C (фронтенд) и всем, кто рисует UI/графики. Это адаптация
проверенной методики построения графиков и интерфейса под цвета Т-Банка.
Claude Code читает этот файл перед тем, как писать CSS/график.

## 1. Цветовые роли (CSS custom properties)

```css
:root {
  color-scheme: light;
  --surface-1:      #F5F4EF;   /* фон */
  --surface-card:   #FFFFFF;   /* карточки */
  --text-primary:   #1C1C1E;   /* чёрный Т-Банка */
  --text-secondary: #52514E;
  --text-muted:     #898781;
  --accent:         #FFDD2D;   /* жёлтый Т-Банка — только для акцентов/CTA */
  --accent-ink:     #1C1C1E;   /* текст поверх жёлтого — всегда чёрный, не белый */
  --gridline:       #E1E0D9;
  --border:         rgba(28,28,30,0.10);

  /* статусные цвета — фиксированные, не темизируются */
  --status-good:     #0CA30C;  /* безопасно, остаток растёт */
  --status-warning:  #E0A400;  /* впритык, минимальный запас */
  --status-critical: #D03B3B;  /* уйдёт в минус */

  /* денежные типы — ключевая фича продукта */
  --money-fixed:     #2A78D6;  /* постоянные доходы/расходы — сплошная линия */
  --money-variable:  #EB6834;  /* непостоянные — пунктирная линия / коридор */
}
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) {
    color-scheme: dark;
    --surface-1: #1A1A19; --surface-card: #232322;
    --text-primary: #FFFFFF; --text-secondary: #C3C2B7; --text-muted: #898781;
    --accent: #FFDD2D; --accent-ink: #1C1C1E;
    --gridline: #2C2C2A; --border: rgba(255,255,255,0.10);
    --status-good: #1FBF1F; --status-warning: #F0B923; --status-critical: #E66767;
    --money-fixed: #3987E5; --money-variable: #D95926;
  }
}
:root[data-theme="dark"] { /* те же значения, что в media-блоке выше */ }
```

Правило: жёлтый — **только** для главного действия/акцента (кнопка, заголовок
суммы), никогда как фон большого блока текста. Чёрный текст на жёлтом —
всегда, белый текст на жёлтом не используется (провал контраста).

## 2. График остатка (BalanceChart) — обязательные правила

- **Постоянные деньги** — сплошная линия (`--money-fixed`), **непостоянные** —
  пунктирная (`--money-variable`) или закрашенный «коридор» между
  пессимистичным и оптимистичным сценарием (полупрозрачная заливка того же
  цвета, opacity ~0.15).
- Ноль на оси Y — обязательная горизонтальная линия, чтобы уход в минус был
  визуально резким переходом цвета линии на `--status-critical`.
- **Крестик (crosshair)**: вертикальная линия следует за курсором и снэпится
  к ближайшему дню — не заставляй пользователя целиться в 2px линию.
- **Один тултип на все серии**: при наведении на день показывать все значения
  этого дня сразу (баланс, обязательный платёж если есть, доход если есть) —
  не заставлять наводиться на конкретную линию.
- В тултипе значение — крупное и контрастное, подпись серии — вторична.
- Названия категорий вставлять через `textContent`, не через `innerHTML`
  (это пользовательские/API-данные).
- Каждая точка/маркер — кликабельная зона минимум 24px, даже если сама точка
  меньше.
- Легенда кликабельна (toggle-to-isolate): клик по «непостоянные» гасит эту
  линию, чтобы видеть только гарантированный сценарий.

## 3. Категориальная палитра (для категорий трат, если понадобится)

Порядок важен — так пары соседних цветов различимы и для дальтоников:
`#2A78D6` (синий) → `#EB6834` (оранжевый) → `#1BAF7A` (бирюзовый) →
`#EDA100` (жёлто-охра, НЕ путать с акцентным `--accent`) → `#E87BA4`
(розовый) → `#008300` (зелёный) → `#4A3AA7` (фиолетовый) → `#E34948`
(красный). Больше 3 серий одновременно на одном графике — сворачивать
в «Другое» или разносить по отдельным мини-графикам.

## 4. Статусы (иконка + текст, никогда только цвет)

| Роль | Когда | Цвет |
|---|---|---|
| good | остаток весь горизонт ≥ порога | `--status-good` |
| warning | остаток близко к нулю, но не уходит в минус | `--status-warning` |
| critical | остаток уходит в минус | `--status-critical` |

Никогда не показывать только цветной кружок без слова рядом
(«Безопасно» / «Впритык» / «Уйдёшь в минус») — это и доступность, и просто
понятнее с первого взгляда.

## 5. Общие правила интерфейса

- Один ряд фильтров/переключателей — сверху блока, никогда внутри карточки.
- При пересчёте (после ввода новой траты) старый график остаётся видимым
  с пониженной непрозрачностью, пока не пришёл новый ответ — никаких
  скелетонов и дёрганья макета.
- Крупные суммы (Hero-цифра) — обычный системный шрифт, не декоративный,
  моноширинные цифры (`font-variant-numeric: tabular-nums`) — только там,
  где числа должны быть выровнены в столбик (таблица «Как мы проверяли»).
- Кнопка-акцент (жёлтая) — одна на экран максимум, для главного действия
  («Проверить покупку», «Продолжить»).
